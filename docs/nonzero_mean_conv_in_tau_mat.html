Restored experiment and its relation to the mean-zero studies

This notebook restores a previously computed nonzero-mean zero-shift experiment. It is separate from the corrected mean-zero true_diff_* notebooks and from the single-sine zero-shift benchmark. It uses all nine exponents \(\alpha=0.9,\ldots,1.7\) and the same connected length-(1,2) tadpole. The full archived numerical results are copied to a distinct filename; restoring and knitting do not rerun the PDE computation.

Let \(u_{\rm zero}\) denote the solution with the original smooth mean-zero data. Here the initial condition and forcing are \[ u_0^{\rm added}=1+\frac{10}{\sqrt{16}}\sum_{j\in\mathcal J}e_j, \qquad f^{\rm added}(s,t)=1+10\sin(\pi t)e_7(s), \qquad \mathcal J=\{5,6,8,\ldots,21\}. \] At \(\kappa=0\), the Kirchhoff fractional Laplacian annihilates constants, so \[ u_{\rm added}(s,t)=u_{\rm zero}(s,t)+1+t, \qquad \bar u(t)=1+t,\qquad M(t)=3(1+t). \] This identity holds for any of the reported alpha values and diffusion coefficients. It describes the same centered diffusion with an additional uniform component supplied by the forcing. The positive-mode initial norm is 10; the full initial norm is \(\sqrt{103}\). The total mass increases because the forcing has mean 1.

At matching FEM and BE parameters, the numerical solutions satisfy \[ U_{\rm added}^k=U_{\rm zero}^k+(1+t_k)\mathbf1 \] in exact arithmetic. The solver handles this constant component exactly through the separate mean recurrence; it does not approximate it using BRASIL.

Reference solution, mean splitting, and error interpretation

The smooth continuum solution contains the original 17 active positive eigenmodes and an additional basis function one with coefficient 1+t. Analytical sine/cosine hat integrals assemble the initial projection and spatial loads. The sine forcing is averaged exactly over every BE interval, and the constant forcing contributes the load Cone. The fixed gap scale is gamma=1/3. At each step the complete load is split as \[ v=CU^k+\tau(F_{\rm sine}\overline g_{k+1}+C\mathbf1), \quad q=\frac{\mathbf1^Tv}{3},\quad b=v-qC\mathbf1. \] The shifted sparse solves act on b; the returned vector is the centered result plus \(q\mathbf1\). Here \(q=1+t_{k+1}\), up to roundoff. The algorithm and its code mapping are documented in kappa0func.Rmd, Section 4.1.

This study measures the sampled continuous-reference space-time error with a consistent fine-grid mass matrix and right-constant BE reconstruction. For t in (t_(k-1),t_k], the added discrete mean is 1+t_k while the continuous mean is 1+t. Thus the added component does not cancel from this error. At matching parameters and with the exact continuous norm, orthogonality of centered and constant functions gives \[ E_{\rm added}^2=E_{\rm zero}^2+ |\Gamma|\sum_k\int_{t_{k-1}}^{t_k}(t_k-t)^2\,dt =E_{\rm zero}^2+\frac{|\Gamma|T\tau^2}{3}. \] Since the graph length is 3, the additional continuous squared error is Ttau^2. The reported error uses a sampled reference-time sum instead; its constant contribution is \[ (\mathbf1^TC_\star\mathbf1) \sum_\ell w_\ell(t_{k(\ell)}-t_\ell^\star)^2. \] The code uses that same sampled norm as the original studies. It does not replace its quadrature by the continuous Ttau^2 expression. All solver steps are advanced; the reference eigenfunctions evaluate the exact solution rather than forming a truncated numerical evolution scheme.

The restored time study used m=12. The current mean-zero time study uses m=8, so their saved errors cannot be compared using the added-mean identity alone without matching that rational order. The settings here preserve the archived run exactly. The expected temporal slope is 1; both centered BE error and uniform mean reconstruction error contribute.

Choice of settings for reporting

The time grids, fine spatial mesh, reference, and m=12 are retained. Independent matching-parameter reruns reproduced the archived finest-step results for all nine alphas; an m=14 comparison changed their errors by less than 0.00032%. The finest local time slopes are approximately 1.0002. The reported norm includes the constant time-reconstruction error, which also has first-order convergence. The current mean-zero time notebook’s m=8 setting is not silently substituted for this experiment’s m=12.

# Reference curves retain their prescribed slope and are geometrically
# anchored to the data. They are guides, not additional computed errors.
guides <- do.call(rbind,lapply(settings$alpha,function(a) {
    x <- d[d$alpha==a,]
    power <- if(settings$study=="m") -2*pi*sqrt(a/2) else if(settings$study=="tau") 1 else 2
    xx <- if(settings$study=="m") sqrt(x$m) else log(x$axis)
    if(settings$study=="rough_h") power <- a
    x$guide <- exp(mean(log(x$error)-power*xx)+power*xx)
    x
}))
guides$alpha_label <- factor(guides$alpha,levels=settings$alpha)
p <- p+ggplot2::geom_line(data=guides,ggplot2::aes(y=guide),linetype="dashed",alpha=0.6)+
    ggplot2::theme_minimal(base_size=12)+ggplot2::labs(subtitle=sprintf("kappa=0; gamma*=%g",settings$gamma_star))
print(p)
