study_parameters <- list(problem = convergence_parameters, alpha = alpha_vector,

We vary m=1,2,3,4, keeping h=1e-5 and tau=1e-10 fixed. This range is independent of m=8 used in the h/tau studies. The theorem’s root-exponential factor supplies an upper-bound benchmark; finite-order slopes need not equal it, and the curves need not be straight. The legend reports that benchmark and the observed slope without a percentage “agreement error”.

# Compute the error matrix and save at the original main-branch location.
errors_projected <- matrix(NA_real_, length(m_vector), length(alpha_vector))
for (i in seq_along(m_vector)) {
  for (j in seq_along(alpha_vector)) {
    errors_projected[i, j] <- tadpole_convergence_error(
      h = h_fixed, time_step = time_step_fixed, m = m_vector[i],
      alpha = alpha_vector[j], parameters = convergence_parameters
    )
  }
}
save(errors_projected, study_parameters,
     file = here::here("data_files/errors_projected_m.RData"))
# Verify that the fixed-name results belong to the parameters above.
saved <- new.env()
load(here::here("data_files/errors_projected_m.RData"), envir = saved)
stopifnot(identical(saved$study_parameters, study_parameters))
errors_projected <- saved$errors_projected
observed_rates <- numeric(length(alpha_vector))
for (u in 1:length(alpha_vector)) {
  observed_rates[u] <- coef(lm(log(errors_projected[, u]) ~ sqrt(m_vector)))[2]
}

theoretical_rates <- -2 * pi * sqrt(1 - alpha_vector / 2)

Figure 1: Comparison between theoretical and observed convergence behavior for the \(L_2(\Gamma\times(0,T))\)-error with respect to \(m\) on a semi-\(\text{log}_{e}\) scale, with \(m\) plotted on a square-root scale. Dashed lines indicate the theoretical rates, and solid lines represent the observed error curves. The legend below each plot shows the value of \(\alpha\) along with the corresponding benchmark (‘bound’), and observed (‘obs’) rates for each case.
